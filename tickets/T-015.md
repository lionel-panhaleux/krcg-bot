## Problem

The harness pays agents to produce findings, so they produce findings whether or not any exist.

- `pm.md`/`eng.md`/`harness.md` output contract: "Top risks", "Hardest questions — the ones they'd rather not answer", "your value is catching what the requestor missed, not agreeing". Nothing says an empty answer is allowed.
- `refs/harness/INDEX.md` §Review checklist is 8 numbered items run on every audit, framed as questions expecting a yes.

Observed this session: the main loop reported "four review passes at filing" with a causal chain — `.claude/rules/` triggering the pre-commit review — that does not exist. CLAUDE.md's review clause never listed that path.

## Outcome

A speculative risk costs the agent that raises it. "Nothing found" is a complete answer.

## Advisor input

`harness`: the evidence handed to it contained two false claims; it caught both. The pass that works is the one that verifies rather than the one that hunts.

## Grilling record

Lionel, 2026-07-29: fix both surfaces — output contracts and the checklist. Rejected softening the adversarial framing itself: the opposite failure is an advisor that agrees with everything.

## Tasks

1. `pm.md`, `eng.md`, `harness.md`: risks and questions must point at something in the repo, current docs, or the diff. "No risk found" is a valid, non-failing answer.
2. `refs/harness/INDEX.md`: the checklist is a sweep, not a quota — a clean pass is a result, and an empty `harness-audit:` marker is the expected case (16 of 23 to date).
