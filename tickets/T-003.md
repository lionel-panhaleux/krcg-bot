## Problem

`tests/test_bot.py` is `def test_embeds(): assert True`, while `conftest.py` pays
a google.com probe, a KRCG static-server probe and a full `vtes.VTES.load()` to
assert nothing. This is the only gate standing between a change and the live
instance.

The gate is also dead upstream. `origin/master` carries only
`.github/workflows/static.yml` ("Validation"); every run since 2025-08 fails in
11–15s because it matrixes 3.10–3.13 against `requires-python = ">=3.13"`, and
because both legs call `uv run just` with `just` absent from the dev group and
from the runner. The corrected `test.yml` is unpushed and hits the same `just`
failure.

## Outcome

A suite that fails when the embeds or components are wrong, running green in CI
on every push and PR. Releasing becomes possible again — Lionel gated the next
release on this being green.
