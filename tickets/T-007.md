## Problem

`.claude/agents/{pm,eng,harness}.md` set only `name` and `description`. With no
`color`, the three are visually indistinguishable in the task list and
transcript — and this session ran two advisors concurrently.

## Outcome

Each agent carries a `color` that maps to its domain.

## Grilling record

Lionel: "use sensible colors for our agents here" — the choice delegated, so
no round was run.

`color` is a supported subagent frontmatter field taking `red`, `blue`,
`green`, `yellow`, `purple`, `orange`, `pink`, `cyan` — verified against
current docs (context7, `code.claude.com/docs/en/sub-agents`), not recall.

## Tasks

- `eng` → `blue`, `pm` → `green`, `harness` → `purple`: technical, product,
  meta.
- Verify: all three parse as agents and appear with their color on next spawn.
