## Problem

The main session's system prompt carried "Do not call the AgentTool unless the
user requested it". It is in none of this repo's files — verified by grepping
`CLAUDE.md`, all of `.claude/` (settings, agents, skills, rules, hooks),
`~/.claude/settings.json` and `~/.claude/CLAUDE.md` for
`AgentTool|subagent|disableAgent`; the only hit is `.claude/skills/ticket/`
asking *for* subagents. Lionel did not set it.

Two harness mechanisms depend on the Agent tool and silently did not run for a
whole session: `/ticket` step 3 advisors, and the Working-doctrine clause
"Substantive changes get an independent agent review before commit". Eight
commits landed unreviewed and nothing broke — which is the second problem.

## Outcome

The review clause says what is actually enforced, and carries Lionel's standing
request in his own voice, so a session whose system prompt allows a
user-requested exception can honour it. `platform.md` records the fact that
makes the clause legible to a future audit.

## Advisor input

harness:
- CLAUDE.md, not a hook. `SessionStart` stdout is script-generated text, not
  Lionel's instruction: it launders an authorization through a machine and
  hides it from anyone reading CLAUDE.md. Hooks cannot compel delegation
  anyway — they can only gate on an artifact, and a review leaves none.
- Provenance is the whole game: attribution plus ticket id is what makes it a
  standing request rather than self-granted permission. **Never write "the
  system-prompt restriction doesn't apply"** — that is a loophole, not an
  authorization.
- Scope to two triggers (reviews, `/ticket` advisors), never "always":
  over-delegation burns the token mandate.
- `platform.md` records no system-prompt fact, so the next audit deletes an
  unexplained authorization line as noise.

## Grilling record

Lionel, live, one round:
- **He did not set the restriction** — platform or launch default. So the
  clause restores what the harness always assumed rather than contradicting a
  choice of his.
- **Scope the review clause down**: it applies to bot code and constitutional
  docs only. Tombstones, plan bookkeeping and refs corrections are exempt —
  which is most of what shipped today.
- **No retro-review** of this session's unreviewed commits; the scoped rule
  would have exempted nearly all of them anyway.

Strategic: it is a meaning-change to a constitutional doc. Filed `todo` on
Lionel's live sign-off during grilling, not `awaiting-sign-off`.
